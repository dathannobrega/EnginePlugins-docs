# Flight

## For players

### Enable and disable
- Use `/f fly` to toggle flight within the clan's territory.
- When leaving the territory, flight turns off automatically.

### Requirements
- Flight is an upgrade the clan can unlock; ask your leader to buy it in the upgrades menu.

## For administrators

### Configuration keys (`config.yml`)
- `upgrades.flight`: cost to unlock flight for the clan.

### Permissions
- `raidengine.clan.user` (or appropriate clan role) to use `/f fly`.
- `raidengine.antiglitch.bypass` bypasses anti-glitch checks (staff only).

Adjust the cost in `upgrades.flight` according to the server's economy.
