# Portais e Warps

## Para jogadores
- Use `/f warp <nome>` para se teletransportar para warps do seu clã.
- Alguns servidores teleportam automaticamente ao entrar em portais gerenciados por plugin.

## Para administradores
- Warps de clã são gerenciados pelos jogadores: `/f setwarp <nome> <senha>` e `/f delwarp <nome>`.
- Portais globais do servidor dependem do plugin de portais usado; o RaidEngine não os cria/nem gerencia.
