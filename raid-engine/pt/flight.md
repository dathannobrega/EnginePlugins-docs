# Voo

## Para jogadores

### Ativar e desativar
- Use `/f fly` para alternar o voo dentro do território do clã.
- Ao sair do território, o voo desliga automaticamente.

### Requisitos
- O voo é um upgrade que o clã pode desbloquear; peça ao líder para comprar no menu de upgrades.

## Para administradores

### Chaves de configuração (`config.yml`)
- `upgrades.flight`: custo para desbloquear o voo para o clã.

### Permissões
- `raidengine.clan.user` (ou cargo apropriado) para usar `/f fly`.
- `raidengine.antiglitch.bypass` ignora checagens anti-glitch (staff).

Ajuste o custo em `upgrades.flight` conforme a economia do servidor.
